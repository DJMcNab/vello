# Fonts used for the glyph comparisons

The fonts are:

- Source Serif 4 (<https://fonts.google.com/specimen/Source+Serif+4/about>), OFL Licensed
- Arimo (<https://fonts.google.com/specimen/Arimo/about>) Apache 2.0 License

These can be downloaded using the shell script (which assumes curl is installed). This path is for the workspace root:

```sh
chmod +x ./sparse_strips/vello_cpu/examples/glyph_comparisons/fonts/download_fonts.sh
./sparse_strips/vello_cpu/examples/glyph_comparisons/fonts/download_fonts.sh
```
